Write a C program for an OS project that multiplies two large matrices using parallel processes. Use fork() to create a child process for each CPU core, and use Shared Memory (shmget) so they can all write to the same result matrix. Optimize the code by transposing the second matrix to make it faster for the CPU cache. Finally, automatically detect the system username , RAM(to safely run the larger matrix size) and save the time results into a text file called benchmarks.txt.
